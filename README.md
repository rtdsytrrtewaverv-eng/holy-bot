# 🤖 Telegram-бот «Файл за подписку»

Бот с механикой: пользователь переходит по ссылке из канала → проверяется подписка → выдаётся файл.

## 🚀 Быстрый запуск

```bash
pip install -r requirements.txt
python bot.py
```

> ☁️ **Хотите запустить бесплатно 24/7?** Смотрите [REPLIT.md](REPLIT.md) —
> пошаговая инструкция для Replit.

## ⚙️ Настройка

1. Скопируйте `.env.example` → `.env`
2. Заполните:
   - `BOT_TOKEN` — токен бота от @BotFather
   - `ADMIN_ID` — ваш Telegram user ID (получить у @userinfobot)
   - `CHANNEL_ID` — ID канала @holy_IPA (например, `-1001234567890`)

## 📋 Команды

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и меню |
| `/start file_<slug>` | Deep-link для получения файла |
| `/admin` | Админ-панель |
| `/help` | Помощь |
| `/support` | Поддержка |
| `/cancel` | Отмена текущего действия |

## 👑 Админ-панель

Всё управление через бота (`/admin`):

- **📁 Файлы** — добавление/редактирование/удаление, получение ссылок
- **📢 Каналы** — управление каналами для проверки подписки
- **💬 Тексты и медиа** — замена всех текстов и картинок
- **📣 Рассылка** — массовая рассылка с фильтрами
- **👥 Пользователи** — список, поиск, бан
- **📊 Статистика** — пользователи, скачивания
- **⚙️ Настройки** — вкл/выкл подписку, тех.работы, админы
- **💾 Бэкап** — скачать/загрузить БД

## 🔗 Ссылка для файла

В админке: 📁 Файлы → выберите файл → 🔗 Получить ссылку.

Формат: `https://t.me/YourBot?start=file_<slug>`

Эту ссылку нужно вставить в кнопку поста канала.
