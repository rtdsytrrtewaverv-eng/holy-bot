# 🤖 Telegram-бот «Файл за подписку»

Бот с механикой: пользователь переходит по ссылке из канала → проверяется подписка → выдаётся файл.

## 🚀 Быстрый запуск

```bash
pip install -r requirements.txt
python bot.py
```

## ⚙️ Настройка

1. Скопируйте `.env.example` → `.env`
2. Заполните:
   - `BOT_TOKEN` — токен бота от @BotFather
   - `ADMIN_ID` — ваш Telegram user ID (получить у @userinfobot)
   - `CHANNEL_ID` — ID канала @holy_IPA (например, `-1001234567890`)

## 📋 Команды

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и меню |
| `/start file_<slug>` | Deep-link для получения файла |
| `/admin` | Админ-панель |
| `/help` | Помощь |
| `/support` | Поддержка |
| `/cancel` | Отмена текущего действия |

## 🆕 Возможности

- **📦 Несколько файлов в одной кнопке** — к записи можно привязать любое число вложений; по одной ссылке/кнопке пользователь получает все файлы сразу.
- **📦 Массовое добавление файлов** — отправьте несколько файлов подряд, задайте общие название/описание/обложку — бот создаст их разом со ссылками (slug генерируется автоматически из имени файла).
- **📚 Библиотека приложений** — отдельный раздел со списком приложений, доступный **только подписчикам** каналов, указанных в админке.
- **🖼 Обложки файлов** — для каждого файла можно задать картинку, которая отправляется перед самим файлом.
- **🎨 Цвета кнопок** — в настройках выбирается цвет кнопок меню, экрана файла, библиотеки и кнопки «Как установить?» (🔵 синяя / 🟢 зелёная / 🔴 красная / ⚪ по умолчанию).
- **✍️ Чистые подписи** — при выдаче файла показывается только название и описание. Если описание не задано — показывается только название; если и его нет — приходит только файл с кнопками.

## 📦 Несколько файлов в одной кнопке

Пример: приложение GTok состоит из 3 файлов — добавьте их к одной записи.

1. **📁 Файлы → файл → ✏️ Редактировать → 📦 Вложения** (или кнопка «📦 Вложения» в карточке).
2. Нажмите **➕ Добавить вложение** и отправьте файлы по одному (любое количество).
3. Каждый файл появляется в списке. Когда закончите — нажмите **✅ Готово**.
4. Готово — по ссылке `?start=file_<slug>` и в библиотеке пользователь получит **все** файлы записи.

Обложка, название, описание и кнопка «Как установить?» задаются один раз для всей записи.
Удалить лишнее вложение можно кнопкой **🗑 <имя>** в списке вложений.


## 📦 Массовое добавление файлов

**📁 Файлы → 📦 Добавить несколько**. Отправьте файлы по одному, затем «✅ Готово»
и укажите общее название, описание, ссылку и обложку. Пустой slug не нужен —
он создаётся автоматически из имени файла (например `my_app_ipa`, `my_app_ipa-2`).

## 🔄 Перенос на другой хостинг

Все данные лежат в одном файле `bot_data.db`. Скачать/загрузить его можно
прямо из бота: **👑 Админка → 💾 Бэкап**. Подробная инструкция —
[MIGRATION.md](MIGRATION.md).


## 📚 Библиотека приложений

Включается в **⚙️ Настройки → 📚 Вкл/Выкл библиотеку**. Показывается пользователю
кнопкой «Библиотека» на стартовом экране (текст кнопки меняется в **💬 Тексты и медиа**).

В библиотеку попадают файлы с флагом «в библиотеке». Переключить можно на экране
файла в админке (**📁 Файлы → файл → 📚 Добавить/Убрать из библиотеки**).

Доступ к библиотеке проверяется так же, как к файлам: пользователь должен быть
подписан на все обязательные каналы из раздела **📢 Каналы**.

## 👑 Админ-панель

Всё управление через бота (`/admin`):

- **📁 Файлы** — добавление по одному или **пачкой**, редактирование/удаление, обложки, библиотека, ссылки
- **📢 Каналы** — управление каналами для проверки подписки
- **💬 Тексты и медиа** — замена всех текстов (включая библиотеку) и картинок
- **📣 Рассылка** — массовая рассылка с фильтрами
- **👥 Пользователи** — список, поиск, бан
- **📊 Статистика** — пользователи, скачивания
- **⚙️ Настройки** — вкл/выкл подписку, тех.работы, библиотеку, **цвета кнопок**, админы
- **💾 Бэкап** — скачать/загрузить БД

## 🔗 Ссылка для файла

В админке: 📁 Файлы → выберите файл → 🔗 Получить ссылку.

Формат: `https://t.me/YourBot?start=file_<slug>`

Эту ссылку нужно вставить в кнопку поста канала.
