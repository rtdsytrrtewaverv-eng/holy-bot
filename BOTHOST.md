# 🤖 Запуск бота на bothost.ru

## Что нужно

1. Аккаунт на https://bothost.ru
2. Публичный GitHub-репозиторий с этим проектом
3. Токен бота от @BotFather

---

## Шаг 1. Создайте бота на bothost

1. Зайдите на https://bothost.ru → **Войти**
2. В панели нажмите **«Создать бота»** / **«Добавить бота»**
3. Выберите способ загрузки: **GitHub**

## Шаг 2. Укажите репозиторий

В настройках бота заполните:

| Поле | Значение |
|------|----------|
| **Ссылка на репозиторий** | `https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ` |
| **Ветка** | `main` |
| **Файл запуска** | `bot.py` |
| **Тип сборки** | Docker (если есть выбор) |

> ⚠️ Репозиторий должен быть **публичным**, иначе сборка упадёт
> с ошибкой `could not read Username for 'https://github.com'`.

## Шаг 3. Добавьте переменные окружения

В разделе **«Переменные»** / **«Environment»** добавьте:

| Переменная | Значение |
|-----------|----------|
| `BOT_TOKEN` | токен бота (от @BotFather) |
| `ADMIN_ID` | ваш Telegram ID (число) |
| `CHANNEL_ID` | ID канала, например `-1004294939675` |

Как узнать свой Telegram ID: напишите @userinfobot.

## Шаг 4. Запустите

Нажмите **«Запустить»** / **«Собрать»** / **Deploy**.

В логах должно появиться:
```
Инициализация базы данных...
Бот запущен!
Run polling for bot @ваш_бот ...
```

## Важные моменты

### База данных
Файл `bot_data.db` создаётся автоматически при первом запуске.
**Делайте бэкапы**: админка в боте → 💾 Бэкап → 📥 Скачать БД.

### Бот должен быть админом канала
Чтобы проверка подписки работала — добавьте бота в канал
`@holy_IPA` как **администратора**.

### Один экземпляр
Не запускайте бота одновременно на нескольких хостингах с одним
токеном — будет ошибка `Conflict: terminated by other getUpdates`.

---

## Если сборка падает

| Ошибка | Решение |
|--------|---------|
| `could not read Username for github` | Репозиторий приватный → сделайте публичным |
| `ModuleNotFoundError` | Проверьте `requirements.txt` в репозитории |
| `Unauthorized` | Неверный `BOT_TOKEN` в переменных |
| `chat not found` | Неверный `CHANNEL_ID` или бот не в канале |
| `Conflict` | Запущено два экземпляра бота |

## Файлы проекта

- `bot.py` — точка входа
- `Dockerfile` — сборка образа (для bothost)
- `Procfile` — команда запуска `worker: python bot.py`
- `requirements.txt` — зависимости
- `runtime.txt` — версия Python

При необходимости укажите команду запуска вручную: `python bot.py`.
