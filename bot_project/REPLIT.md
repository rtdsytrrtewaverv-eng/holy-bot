# 🚀 Запуск бота на Replit (бесплатно)

## Шаг 1. Загрузите проект на Replit

**Способ А (через GitHub — рекомендуем):**
1. Залейте папку `bot_project` в свой репозиторий GitHub
2. На https://replit.com → **Create Repl** → **Import from GitHub**
3. Вставьте ссылку на репозиторий → **Import**

**Способ Б (вручную):**
1. Создайте новый Repl на Python
2. Скопируйте все файлы проекта в редактор Replit

## Шаг 2. Добавьте секреты (Secrets)

В Replit слева откройте **🔒 Secrets** (или Tools → Secrets) и добавьте:

| Key          | Value                          |
|--------------|--------------------------------|
| `BOT_TOKEN`  | токен вашего бота              |
| `ADMIN_ID`   | ваш Telegram ID (число)        |
| `CHANNEL_ID` | ID канала (например `-100...`) |

⚠️ **НЕ** создавайте `.env` на Replit — используйте Secrets.

## Шаг 3. Запустите

Нажмите большую кнопку **▶ Run**.

В консоли должно появиться:
```
Run polling for bot @your_bot ...
Keep-alive сервер запущен на порту 8080
```

## Шаг 4. Чтобы Repl не засыпал (важно!)

Бесплатный Repl засыпает без активности. Бот сам поднимает
веб-сервер на порту 8080 — нужно его периодически пинговать:

1. Зарегистрируйтесь на https://uptimerobot.com (бесплатно)
2. **Add New Monitor** → тип **HTTP(s)**
3. URL: адрес вашего Repl (виден в окне **Webview** справа, вида
   `https://<имя>.<логин>.repl.co`)
4. Interval: **5 minutes** → Save

Теперь UptimeRobot каждые 5 минут пингует бота → Repl не засыпает.

## Шаг 5. Проверка

- Откройте бота в Telegram → `/start`
- `/admin` → админ-панель

## ❗ Важные нюансы

### Сохранность базы данных
Файл `bot_data.db` хранится на диске Repl. Если Repl **удалится** —
данные пропадут. Делайте бэкап: **админка → 💾 Бэкап → 📥 Скачать БД**.

### Бот должен быть админом канала
Добавьте бота в канал `@holy_IPA` как **администратора**, иначе проверка
подписки не работает. Бот при старте пришлёт предупреждение в ЛС.

### Токен в безопасности
Токен хранится в Secrets Replit — он не виден в коде. Никому не передавайте.

## 🔧 Если бот не запускается

1. **`ModuleNotFoundError`** — в консоли Replit выполните:
   ```
   pip install -r requirements.txt
   ```

2. **`Unauthorized`** — неверный `BOT_TOKEN` в Secrets.

3. **`chat not found`** — неверный `CHANNEL_ID` или бот не добавлен в канал.

4. **Бот молчит** — проверьте консоль, там будут логи с ошибками.

5. **`Conflict: terminated by other getUpdates`** — запущено два экземпляра
   бота одновременно. Остановите лишний.
